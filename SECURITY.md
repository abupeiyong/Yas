# Security Policy

Yas is a personal fork of [HAPI](https://github.com/tiann/hapi).

Do not include access tokens, session transcripts, private code, or credentials in public issues.

See the [2026-10-03 outbound-data security review](docs/security/2026-10-03-outbound-review.md) for the initial findings, scope, verification, and remaining work. Branding changes do not disable inherited third-party integrations.

For issues inherited from HAPI, use [upstream private vulnerability reporting](https://github.com/tiann/hapi/security/advisories/new). For Yas-specific issues, use [GitHub private vulnerability reporting](https://github.com/abupeiyong/Yas/security/advisories/new) when enabled by the repository owner; do not fall back to public disclosure of secrets.
